Este projeto é uma página inicial no estilo do Mercado Livre que foi entregue **com erros de código**. A missão é corrigir cada um deles e devolver o site ao funcionamento correto, seguindo o layout dos protótipos.

Cada erro corrigido vira **um commit isolado**. Assim, o histórico do Git mostra, passo a passo, como o site saiu do estado quebrado até a versão final. 🧩

---

## 🎯 Objetivo

- 🐛 Encontrar e corrigir os erros de código do projeto (a atividade fala em 10 erros)
- 🧱 Deixar a estrutura, o estilo e o comportamento do site de acordo com os protótipos em `src/assets/prototipos/`
- 📜 Registrar cada correção em um commit separado, com a mensagem começando por `fix:`

---

## ✨ Recursos

| 🎯 Recurso | 🧭 O que faz |
|---|---|
| 🌗 **Tema claro e escuro** | Um ícone no cabeçalho alterna a paleta de cores de toda a página |
| 🔍 **Barra de busca** | Campo de pesquisa centralizado no cabeçalho |
| 🖼️ **Banner promocional** | Imagem de destaque logo abaixo do cabeçalho |
| 🃏 **Cartões de destaque** | Seis temas com imagem, texto e botão *Mostrar*, em grade responsiva |
| ✨ **Efeitos de interação** | Transições suaves de cor e de fundo ao alternar o tema |
| 📱 **Layout responsivo** | Os cartões se ajustam em telas de até 768px e 480px |
